# 破坏性变更 — Corex v14（MCP Agent 面）

v14 对 **corex-mcp** 做破坏性重构：删除摊平 action tools 与一切兼容路径，只保留
渐进披露用的 meta-tool。无别名、无 deprecated 双路径、无 `--full-tools`。

---

## 1. 删除摊平 tools

| 旧面 | 新面 |
| ---- | ---- |
| `tools/list` ≈ 80 个 `file_copy` 式工具 + `corex_run_directive` | **仅 7 个**：`corex_actions` / `corex_action` / `corex_invoke` / `corex_directives` / `corex_directive` / `corex_validate` / `corex_run` |
| 动作 id → snake tool 名 | 经 `corex_invoke` 传 `id` |
| `corex_run_directive` | **`corex_run`**（`name` \| `path` oneOf） |
| id 字符串启发式 `destructiveHint` | `find_risk_annotations`（读权限声明） |
| 假 capability `listChanged` | **去掉**（未实现推送） |

Agent / 编辑器配置须改用新工具名；禁止依赖旧摊平名。

---

## 2. 配置 `[mcp]`

```toml
[mcp]
allow_actions = []
allow_directives = []
is_deny_default = false
```

未知键仍被拒。`is_deny_default = true` 时空白名单拒绝执行，并禁止 `corex_run` 的
`path` 旁路。

---

## 3. 错误与审计

- 失败：`structuredContent: { code, message, retryable }`；`content` 同文案。
- 审计可选字段：`tool` / `action_or_directive` / `session`。

---

## 迁移清单

1. 客户端去掉对 `file_*` / `shell_run` 等摊平 tool 的调用。
2. 将 `corex_run_directive` 改为 `corex_run`；参数改为 name **或** path 二选一。
3. 发现流改为 `corex_actions` → `corex_action`（或指令对等路径）。
4. 企业场景打开 `is_deny_default` 并填写 `allow_*`。
