# 破坏性变更 — Corex v11

v11 把 UI 交互式选控件的能力统一叫「Inspect」。文档里早就这么叫，但动作 id、CLI 子命令和
权限项还留着最早的 `pick`。这次一次改完，**不留旧别名**：旧 id 会明确报 `action_not_registered`，
不会静默回退。

---

## 1. `ui.element.pick` → `ui.element.inspect`

| 位置                              | 旧                           | 新                             |
| --------------------------------- | ---------------------------- | ------------------------------ |
| 动作 id / 权限项 / 审计字段        | `ui.element.pick`            | `ui.element.inspect`           |
| CLI 子命令                        | `corex ui element pick`      | `corex ui element inspect`     |
| Rust 入口                         | `corex_registry::ui_pick::probe_pick`   | `corex_registry::ui_inspect::probe_inspect` |
| 窗口类型                          | `CorexUiPick*`               | `CorexUiInspect*`              |

同步更新的位置：企业部署示例 [`config/enterprise.toml`](../../config/enterprise.toml)、
内置 Action 表（[内置 Action](../reference/内置Action.md)）、Tauri inspector 页。

### 要做什么

- 指令里 `action: ui.element.pick` → `action: ui.element.inspect`。
- `[plugins].disabled` / `disabled_actions` 若写的是 `ui.element.pick`，**按 id 匹配会当成
  不存在的动作，禁用不再生效**——改成新名字才有效。
