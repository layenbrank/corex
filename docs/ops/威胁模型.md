# 威胁模型（corex v5 内置）

## 信任边界

| 组件 | 信任级别 | 说明 |
|------|----------|------|
| Directive YAML 作者 | 半可信 | 可声明步骤与权限 |
| corex-daemon | 可信 | 持有 IPC token，执行 Action |
| 内置 Action | 可信代码 | 编译期 feature 门控 |
| 外部 HTTP 目标 | 不可信 | `http.send` |
| 本地文件系统 | 敏感 | `file.write` 补丁模式等 |

## 高风险 Action

| Action | 风险 | 缓解 |
|--------|------|------|
| `shell.run` / `exec.run` | 任意进程 / 脚本 | `permissions.shell`；按 Action 的 `disabled_actions`；审计建议显式 `host`；`filesystem_roots` 约束 `exec.run` 的 **script** 与两者的 **cwd**（`shell.run` 的 **command** 不做路径沙箱——走 PATH） |
| `ui.*` | 输入注入、应用控制 | `permissions.ui`；企业预设默认关闭 |
| `capture.screenshot` / `capture.ocr` / `capture.monitors` | 屏幕 PII/机密；显示器布局 | `permissions.capture`；企业预设禁用；历史不写 OCR 全文 |
| `keyring.*` / `scan.os` | 密钥 / 主机清单 | `permissions.secret`（keyring）；企业 `disabled_actions` |
| `file.write`（`regex` 模式） | ReDoS | 模式长度与输出字节上限 |
| `clipboard.set`（`image`） | 经剪贴板外泄 | `permissions.clipboard` |
| `corex ui` 探测 CLI | 枚举窗口/控件；stdout 可能含 PII | 与 daemon 相同的 `plugins.disabled` / `disabled_actions` / `strict_permissions`；审计为 `ui.probe`；可用 `--redact` |

## 已移除 / 已迁移

- **`capture.clipboard`** 已移除 — 改用 `clipboard.set`，`format: image` 或 `text`。
- **`ui.find` / `ui.wait`（窗口等待语义）** — 窗口等待改用 `ui.window.find` / `ui.window.wait`（固定休眠仍可用 `ui.wait`）。

## 数据流

```
Directive → Pipeline → ActionStore → builtin / WASM
                ↓
         history.jsonl（指令级）
         audit.jsonl（步骤级，已脱敏）
```

## 脱敏策略（已实现）

| 数据 | 是否记录 |
|------|----------|
| `action_id`、`step_id`、`duration_ms`、`ok` | 是（`audit.jsonl`） |
| `denied`（权限拒绝）、`error_kind` | 是（失败时；`denied: true` 表示权限拒绝） |
| `ui_phase`、`error_code`、`selector_hint` | 是（适用时；`selector_hint` 已脱敏） |
| 指令历史 `error` | 短类别 + 截断 / 路径脱敏文本（`history.jsonl`，前缀常为 `kind:`） |
| HTTP body、OCR 全文、剪贴板载荷 | **否** |
| 敏感 Action 参数 | **不记录**（无参数值、无密钥转储） |

## 合规提示

- UI 自动化示例（如微信）为**实验性**；见 [compliance.md](合规说明.md)。
- 企业部署请启用 `strict_permissions` + `filesystem_roots`。
- 本地 `corex run` 绕过 daemon IPC；见 [enterprise-deploy.md](企业部署.md#cli-信任边界)。
