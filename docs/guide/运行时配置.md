# 运行时配置

Corex 从 **`config/corex.toml`**（仓库模板）或 **`<数据目录>/config.toml`** 加载配置。CLI 与 Daemon 共用同一套逻辑。

数据目录：

| 平台 | 路径 |
|------|------|
| Windows | `%LOCALAPPDATA%\corex\` |
| Linux | `~/.local/share/corex/` |
| macOS | `~/Library/Application Support/corex/` |

---

## 配置文件位置

按优先级（找到即用）：

1. 仓库根目录 `config/corex.toml`（开发时）
2. `<数据目录>/config.toml`（部署后推荐复制到此）

---

## 配置段说明

### `[daemon]` — IPC 服务

| 键 | 说明 | 默认 |
|----|------|------|
| `socket_path` | Unix socket 相对名或绝对路径；Windows 为 `\\.\pipe\corex` | `corex.sock` |
| `lock_path` | 单例锁文件 | `corex.lock` |
| `token` | IPC 鉴权密钥；空则读/写 `<数据目录>/token` | （自动生成） |

环境变量 **`COREX_TOKEN`** 优先于配置文件中的 `token`。

### `[plugins]` — 插件

| 键 | 说明 |
|----|------|
| `plugin_dir` | WASM 插件目录（相对数据目录或绝对路径） |
| `disabled` | 禁用的插件 ID 列表 |
| `disabled_actions` | 禁用的 Action ID 列表（如 `shell.run`） |

### `[history]` — 执行历史

| 键 | 说明 |
|----|------|
| `enabled` | 是否写入 JSONL 历史 |
| `file` | 历史文件名（相对数据目录） |

### `[logging]`

| 键 | 说明 |
|----|------|
| `level` | `trace` / `debug` / `info` / `warn` / `error` |
| `json` | 结构化 JSON 日志（便于 SIEM） |

### `[runtime]` — 引擎行为

| 键 | 说明 | 默认 |
|----|------|------|
| `max_parallel` | `parallel` 块最大并发 | 8 |
| `step_timeout_secs` | 单步超时（0=不限） | 0 |
| `strict_permissions` | 拒绝未声明 permissions 的指令 | false |
| `filesystem_roots` | 文件类 Action 允许访问的根路径（空=不限制） | [] |
| `ui_profile` | UI 自动化预设：`baseline` / `fast` / `patient` | baseline |
| `ui_max_settle_ms` | 单次指令 `ui.wait` 累计上限（fast 预设 2000） | 0 |
| `ui_max_selector_chain` | `selectors[]` 最大长度 | 8 |

#### UI profile 对照

| Profile | `ui_max_selector_chain` | `ui_max_settle_ms` |
|---------|-------------------------|-------------------|
| `baseline` | 8 | 0（不限） |
| `fast` | 5 | 2000 |
| `patient` | 12 | 0 |

详见 [UI 自动化](../topics/UI自动化.md#runtime-ui-profile)。

---

## 示例：企业收紧配置

```toml
[runtime]
strict_permissions = true
filesystem_roots = ["C:/ProgramData/MyApp/data"]

[plugins]
disabled_actions = ["shell.run", "ui.element.click"]

[logging]
json = true
level = "info"
```

配合 [enterprise-deploy.md](../ops/企业部署.md) 与 [enterprise.toml](../../config/enterprise.toml)。
